# Impeccable Design Context

## Design Context

**Project**: NoMoreSlop.com — resource hub for developers who build with AI and care about shipping quality code.

**Target audience**: Developers — WordPress plugin authors, freelancers, solo SaaS founders who use Cursor, Claude Code, or Copilot and want to know if their code is safe to ship. Practical, skeptical of hype, will immediately distrust anything that looks like a marketing team or AI made it.

**Use cases**:
- Find automated code quality tools
- Browse and download agent skills
- Find a human code reviewer
- Read case studies about AI-generated code problems

**Brand personality/tone**: Built by a developer with opinions. Honest, direct, no marketing fluff. Should feel like a senior engineer's personal site — not a startup landing page. Dark, editorial, technical.

**Aesthetic direction**: Editorial brutalist — near-black background (#0a0a0a), Bebas Neue display font, IBM Plex Mono body, amber accent (#f59e0b). Feels like a technical zine. The "NoMoreSlop" wordmark has a red strikethrough on "Slop". Section labels are code-comment style (// RESOURCES).

**What must NOT change**: The overall dark editorial aesthetic, the amber accent, the typing effect on the hero, the Bebas Neue + IBM Plex Mono font pairing.

**Key constraint**: The audience will immediately distrust anything that looks "AI-generated" — generic gradients, purple palettes, glassmorphism, predictable layouts are all instant credibility killers.
